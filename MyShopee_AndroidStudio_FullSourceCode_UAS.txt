--------------------------------------------------------------------------------

Ubah tampilan panel kiri dari "Android" ke "Project" apabila ingin melihat struktur folder fisik, lalu buat paket folder MVVM: data/model, data/remote, data/repository, viewmodel, serta ui/splash, ui/auth, ui/home, ui/category, ui/product, ui/cart, ui/checkout, ui/payment, ui/orders, dan ui/profile.

04. Membuat Backend Cloud & Database (REST API + Supabase SQL) — Skema Tabel users, products, cart, orders, order_items & Keamanan RLS
Target Folder: Cloud Backend URL / Supabase SQL Editor
--------------------------------------------------------------------------------
1. Aplikasi ini menyediakan 2 opsi Cloud Backend yang langsung aktif: (A) Endpoint Cloud REST API siap pakai pada URL aplikasi ini, atau (B) Database Supabase PostgreSQL milik Anda sendiri.

4. KEAMANAN PENTING: Aktifkan Row Level Security (RLS) pada setiap tabel. Pada aplikasi Android, hanya gunakan "anon public key" pada header apikey. JANGAN PERNAH menanamkan "service_role secret key" di dalam kode Android karena APK dapat didekompilasi.

[Daftar 9 Endpoint REST API Cloud Aktif]
Base URL Aktif: https://ais-pre-fehbahgn7hpa2phluispxl-526203982170.asia-east1.run.app/

1. GET    /api/products                  -> Mengambil daftar seluruh produk
2. GET    /api/products?search=cardigan  -> Mencari produk berdasarkan kata kunci
3. POST   /api/cart                      -> Menambahkan produk ke keranjang
4. GET    /api/cart                      -> Mengambil isi keranjang & subtotal
5. PUT    /api/cart/{id}                 -> Mengubah jumlah (kuantitas) / centang produk
6. DELETE /api/cart/{id}                 -> Menghapus produk dari keranjang
7. POST   /api/checkout                  -> Membuat pesanan baru (Alamat Kota Cirebon)
8. POST   /api/payment/simulate?order_id=INV-20261008-001 -> Simulasi bayar VA BCA
9. GET    /api/orders/{id}               -> Mengambil detail dan status pesanan

Tips: Anda bisa mencoba memanggil ke-9 endpoint di atas secara langsung pada menu "Uji REST API" di bagian atas halaman ini.

05. Menghubungkan Aplikasi Android dengan Backend Menggunakan Retrofit — Implementasi Models.kt, ApiService.kt, RetrofitClient.kt, dan ShopeeRepository.kt
Target Folder: app/src/main/java/id/ac/uas/myshopee/data/
--------------------------------------------------------------------------------
1. Buat file Models.kt di dalam folder data/model/ dengan anotasi @SerializedName agar nama field JSON dari backend (seperti image_url, variants_color, total_payment) terpetakan dengan akurat ke properti Kotlin.
2. Buat file ApiService.kt di dalam folder data/remote/ yang berisi deklarasi suspend fun untuk setiap endpoint GET, POST, PUT, dan DELETE.
3. Buat file RetrofitClient.kt dengan BASE_URL mengarah ke server cloud HTTPS sehingga dapat diakses baik dari Emulator Android Studio maupun HP Android fisik.
4. Bungkus setiap pemanggilan API di dalam ShopeeRepository.kt menggunakan blok try-catch dan withContext(Dispatchers.IO) agar kegagalan jaringan tertangani rapi.
Tips: Pastikan akhiran BASE_URL pada Retrofit selalu menggunakan tanda garis miring (slash "/"), contoh: "https://.../".

09. Cara Mengatasi Error yang Mungkin Muncul (Troubleshooting) — Solusi Cepat untuk Masalah Umum Pemula di Android Studio
Target Folder: Logcat & Build Output Android Studio
--------------------------------------------------------------------------------
1. Error "java.lang.SecurityException: Permission denied (missing INTERNET permission)": Pastikan baris <uses-permission android:name="android.permission.INTERNET" /> sudah ditulis di AndroidManifest.xml di luar tag <application>, lalu uninstall aplikasi lama di emulator dan Run ulang.
2. Error "Unresolved reference: ActivityHomeBinding": Pastikan viewBinding = true sudah ditambahkan di build.gradle.kts (Module :app) dan Anda sudah menekan "Sync Now" serta memilih menu Build > Rebuild Project.
3. Gambar Produk Tidak Muncul di RecyclerView: Pastikan URL gambar diawali https:// (atau digabung dengan RetrofitClient.BASE_URL) dan perangkat/emulator memiliki koneksi internet aktif.
4. Error "CLEARTEXT communication not permitted": Tambahkan atribut android:usesCleartextTraffic="true" pada tag <application> di AndroidManifest.xml.
5. Aplikasi Crash saat Rotasi atau Pindah Layar: Pastikan data class Product dan Order sudah diberi anotasi @Parcelize dan mengimplementasikan interface Parcelable.
Tips: Selalu buka tab "Logcat" di bagian bawah Android Studio dan ketik filter "okhttp" untuk melihat request & response JSON dari Retrofit secara detail.

-- ============================================================================
-- SKEMA DATABASE MY SHOPEE (PostgreSQL / Supabase SQL Editor)
-- PENTING: Gunakan anon/public key di Android. JANGAN PERNAH menanamkan
-- service_role key di dalam kode aplikasi Android!
-- ============================================================================

-- 1. Tabel Users
CREATE TABLE IF NOT EXISTS public.users (
    id BIGSERIAL PRIMARY KEY,
    full_name VARCHAR(120) NOT NULL,
    email VARCHAR(150) UNIQUE NOT NULL,
    password_hash TEXT NOT NULL,
    phone VARCHAR(30) DEFAULT '0812-2345-6789',
    address TEXT DEFAULT 'Jl. Kartini No. 45, Kec. Kejaksan',
    city VARCHAR(100) DEFAULT 'Kota Cirebon, Jawa Barat 45123',
    created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 2. Tabel Products
CREATE TABLE IF NOT EXISTS public.products (
    id BIGSERIAL PRIMARY KEY,
    name VARCHAR(180) NOT NULL,
    category VARCHAR(50) NOT NULL CHECK (category IN ('Fashion', 'Aksesori', 'Elektronik', 'Tas', 'Sepatu', 'Kecantikan')),
    price INTEGER NOT NULL CHECK (price >= 0),
    rating NUMERIC(2,1) DEFAULT 4.9,
    sold INTEGER DEFAULT 0,
    stock INTEGER DEFAULT 50,
    image_url TEXT NOT NULL,
    description TEXT NOT NULL,
    variants_color TEXT[] DEFAULT ARRAY['Pastel Pink', 'Cream Ivory'],
    variants_size TEXT[] DEFAULT ARRAY['S', 'M', 'L', 'All Size'],
    is_popular BOOLEAN DEFAULT false,
    is_recommended BOOLEAN DEFAULT true,
    created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 3. Tabel Cart (Keranjang Belanja dengan relasi Foreign Key ke users & products)
CREATE TABLE IF NOT EXISTS public.cart (
    id BIGSERIAL PRIMARY KEY,
    user_id BIGINT NOT NULL REFERENCES public.users(id) ON DELETE CASCADE,
    product_id BIGINT NOT NULL REFERENCES public.products(id) ON DELETE CASCADE,
    quantity INTEGER NOT NULL DEFAULT 1 CHECK (quantity > 0),
    variant_color VARCHAR(60) NOT NULL DEFAULT 'Pastel Pink',
    variant_size VARCHAR(40) NOT NULL DEFAULT 'All Size',
    selected BOOLEAN NOT NULL DEFAULT true,
    updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- 4. Tabel Orders (Pesanan & Pembayaran Virtual Account BCA 123 456 7890)
CREATE TABLE IF NOT EXISTS public.orders (

interface ApiService {

    // 1. Mengambil daftar produk & pencarian kata kunci / filter kategori / urutan harga
    @GET("api/products")
    suspend fun getProducts(
        @Query("search") search: String? = null,
        @Query("category") category: String? = null,
        @Query("sort") sort: String? = null
    ): Response<ApiResponse<List<Product>>>

    @POST("api/auth/login")
    suspend fun login(
        @Body request: AuthRequest
    ): Response<ApiResponse<UserProfile>>

    @POST("api/auth/register")
    suspend fun register(
        @Body request: AuthRequest
    ): Response<ApiResponse<UserProfile>>

    // 4. Operasi CRUD Keranjang Belanja
    @GET("api/cart")
    suspend fun getCart(): Response<ApiResponse<List<CartItem>>>

    @POST("api/cart")
    suspend fun addToCart(
        @Body request: AddCartRequest
    ): Response<ApiResponse<CartItem>>

    @PUT("api/cart/{id}")
    suspend fun updateCartItem(
        @Path("id") cartId: Int,
        @Body request: UpdateCartRequest
    ): Response<ApiResponse<CartItem>>

    @DELETE("api/cart/{id}")
    suspend fun deleteCartItem(
        @Path("id") cartId: Int
    ): Response<ApiResponse<CartItem>>

    // 5. Checkout Pesanan (Pengiriman Kota Cirebon)
    @POST("api/checkout")
    suspend fun checkout(
        @Body request: CheckoutRequest
    ): Response<ApiResponse<Order>>

    // 6. Simulasi Pembayaran Virtual Account BCA 123 456 7890 via Backend
    @POST("api/payment/simulate")
    suspend fun simulatePayment(
        @Query("order_id") orderId: String
    ): Response<ApiResponse<Order>>

    @GET("api/orders/{id}")
    suspend fun getOrderById(

package id.ac.uas.myshopee.data.repository

import id.ac.uas.myshopee.data.model.*
import id.ac.uas.myshopee.data.remote.ApiService
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.withContext

class ShopeeRepository(private val api: ApiService) {

    suspend fun getProducts(
        search: String? = null,
        category: String? = null,
        sort: String? = null
    ): Result<List<Product>> = withContext(Dispatchers.IO) {
        try {
            val response = api.getProducts(search, category, sort)
            if (response.isSuccessful && response.body() != null) {
                Result.success(response.body()!!.data)
            } else {
                Result.failure(Exception("Gagal memuat produk (Kode: ${response.code()})"))
            }
        } catch (e: Exception) {
            Result.failure(Exception("Koneksi gagal: Pastikan internet aktif (${e.localizedMessage})"))
        }
    }

    suspend fun getCart(): Result<List<CartItem>> = withContext(Dispatchers.IO) {
        try {
            val response = api.getCart()
            if (response.isSuccessful && response.body() != null) {
                Result.success(response.body()!!.data)
            } else {
                Result.failure(Exception("Gagal memuat keranjang belanja"))
            }
        } catch (e: Exception) {
            Result.failure(Exception("Koneksi jaringan terputus: ${e.localizedMessage}"))
        }
    }

    suspend fun addToCart(productId: Int, quantity: Int, color: String, size: String): Result<CartItem> =
        withContext(Dispatchers.IO) {
            try {
                val req = AddCartRequest(productId, quantity, color, size)
                val response = api.addToCart(req)
                if (response.isSuccessful && response.body() != null) {
                    Result.success(response.body()!!.data)
                } else {
                    Result.failure(Exception("Gagal menambahkan produk ke keranjang"))
                }
            } catch (e: Exception) {
                Result.failure(Exception("Tidak dapat terhubung ke server: ${e.localizedMessage}"))
            }
        }

    suspend fun updateCart(cartId: Int, quantity: Int?, selected: Boolean?): Result<CartItem?> =
        withContext(Dispatchers.IO) {
            try {
                val response = api.updateCartItem(cartId, UpdateCartRequest(quantity, selected))
                if (response.isSuccessful) {
                    Result.success(response.body()?.data)
                } else {
                    Result.failure(Exception("Gagal memperbarui jumlah produk"))
                }
            } catch (e: Exception) {
                Result.failure(Exception("Koneksi gagal saat mengubah keranjang"))
            }
        }

    suspend fun deleteCart(cartId: Int): Result<Boolean> = withContext(Dispatchers.IO) {
        try {
            val response = api.deleteCartItem(cartId)
            if (response.isSuccessful) {
                Result.success(true)
            } else {
                Result.failure(Exception("Gagal menghapus produk dari keranjang"))
            }
        } catch (e: Exception) {
            Result.failure(Exception("Gagal menghubungi server"))
        }
    }

    suspend fun createCheckout(request: CheckoutRequest): Result<Order> = withContext(Dispatchers.IO) {
        try {
            val response = api.checkout(request)
            if (response.isSuccessful && response.body() != null) {
                Result.success(response.body()!!.data)
            } else {
                Result.failure(Exception("Gagal membuat pesanan checkout"))
            }
        } catch (e: Exception) {
            Result.failure(Exception("Error jaringan saat checkout: ${e.localizedMessage}"))
        }
    }

    suspend fun simulateBcaPayment(orderId: String): Result<Order> = withContext(Dispatchers.IO) {
        try {
            val response = api.simulatePayment(orderId)
            if (response.isSuccessful && response.body() != null) {
                Result.success(response.body()!!.data)
            } else {
                Result.failure(Exception("Gagal memverifikasi simulasi pembayaran VA BCA"))
            }
        } catch (e: Exception) {
            Result.failure(Exception("Koneksi terputus saat cek status pembayaran"))
        }
    }

    suspend fun getOrderDetail(orderId: String): Result<Order> = withContext(Dispatchers.IO) {
        try {
            val response = api.getOrderById(orderId)
            if (response.isSuccessful && response.body() != null) {
                Result.success(response.body()!!.data)
            } else {
                Result.failure(Exception("Data pesanan tidak ditemukan"))
            }
        } catch (e: Exception) {
            Result.failure(Exception("Gagal mengambil status pesanan dari server"))
        }
    }
}

package id.ac.uas.myshopee.viewmodel

import androidx.lifecycle.*
import id.ac.uas.myshopee.data.model.*
import id.ac.uas.myshopee.data.remote.RetrofitClient
import id.ac.uas.myshopee.data.repository.ShopeeRepository
import kotlinx.coroutines.launch

class ShopeeViewModel : ViewModel() {

    private val repository = ShopeeRepository(RetrofitClient.apiService)

    private val _products = MutableLiveData<List<Product>>(emptyList())
    val products: LiveData<List<Product>> = _products

    private val _cartItems = MutableLiveData<List<CartItem>>(emptyList())
    val cartItems: LiveData<List<CartItem>> = _cartItems

    private val _subtotal = MutableLiveData<Int>(0)
    val subtotal: LiveData<Int> = _subtotal

    private val _currentOrder = MutableLiveData<Order?>()
    val currentOrder: LiveData<Order?> = _currentOrder

    private val _isLoading = MutableLiveData<Boolean>(false)
    val isLoading: LiveData<Boolean> = _isLoading

    private val _errorMessage = MutableLiveData<String?>(null)
    val errorMessage: LiveData<String?> = _errorMessage

    fun fetchProducts(search: String? = null, category: String? = null, sort: String? = null) {
        viewModelScope.launch {
            _isLoading.value = true
            _errorMessage.value = null
            val result = repository.getProducts(search, category, sort)
            result.onSuccess { list ->
                _products.value = list
            }.onFailure { err ->
                _errorMessage.value = err.message
            }
            _isLoading.value = false
        }
    }

    fun fetchCart() {
        viewModelScope.launch {
            _isLoading.value = true
            val result = repository.getCart()
            result.onSuccess { items ->
                _cartItems.value = items
                calculateSubtotal(items)
            }.onFailure { err ->
                _errorMessage.value = err.message
            }
            _isLoading.value = false
        }
    }

    private fun calculateSubtotal(items: List<CartItem>) {
        val total = items.filter { it.selected }.sumOf { it.price * it.quantity }
        _subtotal.value = total
    }

    fun addProductToCart(productId: Int, quantity: Int, color: String, size: String, onSuccess: () -> Unit) {
        viewModelScope.launch {
            _isLoading.value = true
            val result = repository.addToCart(productId, quantity, color, size)
            result.onSuccess {
                fetchCart()
                onSuccess()
            }.onFailure { err ->
                _errorMessage.value = err.message
            }
            _isLoading.value = false
        }
    }

    fun updateCartQuantity(cartId: Int, newQuantity: Int) {
        viewModelScope.launch {
            val result = repository.updateCart(cartId, quantity = newQuantity, selected = null)
            result.onSuccess { fetchCart() }
            result.onFailure { _errorMessage.value = it.message }
        }
    }

    fun toggleCartItemSelection(cartId: Int, isSelected: Boolean) {
        viewModelScope.launch {
            val result = repository.updateCart(cartId, quantity = null, selected = isSelected)
            result.onSuccess { fetchCart() }
            result.onFailure { _errorMessage.value = it.message }
        }
    }

    fun removeCartItem(cartId: Int) {
        viewModelScope.launch {
            val result = repository.deleteCart(cartId)
            result.onSuccess { fetchCart() }
            result.onFailure { _errorMessage.value = it.message }
        }
    }

    fun submitCheckout(
        name: String,
        phone: String,
        address: String,
        shippingMethod: String,
        onOrderCreated: (Order) -> Unit
    ) {
        viewModelScope.launch {
            _isLoading.value = true
            val req = CheckoutRequest(
                recipientName = name,
                recipientPhone = phone,
                shippingAddress = address,
                shippingCity = "Kota Cirebon, Jawa Barat 45123",
                shippingMethod = shippingMethod
            )
            val result = repository.createCheckout(req)
            result.onSuccess { order ->
                _currentOrder.value = order
                onOrderCreated(order)
            }.onFailure { err ->
                _errorMessage.value = err.message
            }
            _isLoading.value = false
        }
    }

    fun verifyPaymentSimulation(orderId: String) {
        viewModelScope.launch {
            _isLoading.value = true
            val result = repository.simulateBcaPayment(orderId)
            result.onSuccess { updatedOrder ->
                _currentOrder.value = updatedOrder
            }.onFailure { err ->
                _errorMessage.value = err.message
            }
            _isLoading.value = false
        }
    }
}

package id.ac.uas.myshopee.ui.product

import android.view.LayoutInflater

import id.ac.uas.myshopee.databinding.ItemProductGridBinding
import java.text.NumberFormat
import java.util.Locale

class ProductGridAdapter(
    private var products: List<Product> = emptyList(),
    private val onProductClick: (Product) -> Unit,
    private val onFavoriteClick: (Product) -> Unit
) : RecyclerView.Adapter<ProductGridAdapter.ProductViewHolder>() {

    fun submitList(newList: List<Product>) {
        products = newList
        notifyDataSetChanged()
    }

    inner class ProductViewHolder(private val binding: ItemProductGridBinding) :
        RecyclerView.ViewHolder(binding.root) {

        fun bind(product: Product) {
            binding.tvProductName.text = product.name
            binding.tvProductCategory.text = product.category
            binding.tvProductPrice.text = formatRupiah(product.price)
            binding.tvProductRating.text = "★ ${product.rating} · Terjual ${product.sold}"

            // Memuat gambar produk dari URL Backend menggunakan Glide
            val fullImageUrl = if (product.imageUrl.startsWith("http")) {
                product.imageUrl
            } else {
                RetrofitClient.BASE_URL.trimEnd('/') + product.imageUrl
            }

            Glide.with(binding.root.context)
                .load(fullImageUrl)
                .placeholder(R.color.pink_light_surface)
                .centerCrop()
                .into(binding.ivProductImage)

            binding.btnFavorite.setImageResource(
                if (product.isFavorite) R.drawable.ic_heart_filled else R.drawable.ic_heart_outline
            )

            binding.root.setOnClickListener { onProductClick(product) }
            binding.btnFavorite.setOnClickListener { onFavoriteClick(product) }
        }
    }

    override fun onCreateViewHolder(parent: ViewGroup, viewType: Int): ProductViewHolder {
        val binding = ItemProductGridBinding.inflate(
            LayoutInflater.from(parent.context),
            parent,
            false
        )
        return ProductViewHolder(binding)
    }

    override fun onBindViewHolder(holder: ProductViewHolder, position: Int) {
        holder.bind(products[position])
    }

    override fun getItemCount(): Int = products.size

    companion object {
        fun formatRupiah(amount: Int): String {
            val format = NumberFormat.getCurrencyInstance(Locale("in", "ID"))
            return format.format(amount).replace(",00", "")
        }
    }
}

package id.ac.uas.myshopee.ui.auth

import android.content.Intent
import android.os.Bundle
import android.util.Patterns
import android.widget.Toast
import androidx.appcompat.app.AppCompatActivity
import androidx.lifecycle.lifecycleScope
import id.ac.uas.myshopee.data.model.AuthRequest
import id.ac.uas.myshopee.data.remote.RetrofitClient
import id.ac.uas.myshopee.databinding.ActivityLoginBinding
import id.ac.uas.myshopee.ui.home.HomeActivity
import kotlinx.coroutines.launch

class LoginActivity : AppCompatActivity() {

    private lateinit var binding: ActivityLoginBinding

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        binding = ActivityLoginBinding.inflate(layoutInflater)
        setContentView(binding.root)

        binding.btnLogin.setOnClickListener {
            validateAndLogin()
        }

        binding.btnGoToRegister.setOnClickListener {
            startActivity(Intent(this, RegisterActivity::class.java))
        }
    }

    private fun validateAndLogin() {
        val email = binding.etEmail.text.toString().trim()
        val password = binding.etPassword.text.toString().trim()

        if (email.isEmpty() || !Patterns.EMAIL_ADDRESS.matcher(email).matches()) {
            binding.tilEmail.error = "Masukkan alamat email yang valid"
            return
        } else {
            binding.tilEmail.error = null
        }

        if (password.length < 6) {
            binding.tilPassword.error = "Password minimal 6 karakter"
            return
        } else {
            binding.tilPassword.error = null
        }

        lifecycleScope.launch {
            try {
                binding.btnLogin.isEnabled = false
                val response = RetrofitClient.apiService.login(AuthRequest(email = email, password = password))
                if (response.isSuccessful && response.body() != null) {
                    val user = response.body()!!.data
                    Toast.makeText(this@LoginActivity, "Selamat datang, ${user.fullName}!", Toast.LENGTH_SHORT).show()
                    startActivity(Intent(this@LoginActivity, HomeActivity::class.java))
                    finish()
                } else {
                    Toast.makeText(this@LoginActivity, "Email atau password tidak sesuai", Toast.LENGTH_LONG).show()
                }
            } catch (e: Exception) {
                Toast.makeText(this@LoginActivity, "Gagal terhubung ke server: ${e.localizedMessage}", Toast.LENGTH_LONG).show()
            } finally {
                binding.btnLogin.isEnabled = true
            }
        }
    }
}

import android.content.Intent

import id.ac.uas.myshopee.databinding.ActivityHomeBinding

import id.ac.uas.myshopee.ui.category.CategoryActivity

import id.ac.uas.myshopee.ui.product.ProductGridAdapter
import id.ac.uas.myshopee.ui.profile.ProfileActivity
import id.ac.uas.myshopee.viewmodel.ShopeeViewModel

class HomeActivity : AppCompatActivity() {

    private lateinit var binding: ActivityHomeBinding
    private val viewModel: ShopeeViewModel by viewModels()
    private lateinit var productAdapter: ProductGridAdapter

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        binding = ActivityHomeBinding.inflate(layoutInflater)
        setContentView(binding.root)

        setupRecyclerViewGrid()
        setupSearchAndCategories()
        setupBottomNavigation()
        observeViewModel()

        // Muat produk dari Cloud Backend
        viewModel.fetchProducts()
    }

    private fun setupRecyclerViewGrid() {
        productAdapter = ProductGridAdapter(
            onProductClick = { product ->
                val intent = Intent(this, ProductDetailActivity::class.java)
                intent.putExtra("EXTRA_PRODUCT", product)
                startActivity(intent)
            },
            onFavoriteClick = { product ->
                product.isFavorite = !product.isFavorite
                productAdapter.notifyDataSetChanged()
            }
        )
        // Wajib menggunakan GridLayoutManager dengan 2 kolom sesuai spesifikasi UAS
        binding.rvProducts.layoutManager = GridLayoutManager(this, 2)
        binding.rvProducts.adapter = productAdapter
    }

    private fun setupSearchAndCategories() {
        binding.etSearchProduct.addTextChangedListener { editable ->
            val keyword = editable?.toString()?.trim()
            viewModel.fetchProducts(search = keyword)
        }
    }

    private fun setupBottomNavigation() {
        binding.bottomNavigation.selectedItemId = R.id.nav_home
        binding.bottomNavigation.setOnItemSelectedListener { item ->
            when (item.itemId) {
                R.id.nav_home -> true
                R.id.nav_category -> {
                    startActivity(Intent(this, CategoryActivity::class.java))
                    true
                }
                R.id.nav_cart -> {
                    startActivity(Intent(this, CartActivity::class.java))
                    true
                }
                R.id.nav_profile -> {
                    startActivity(Intent(this, ProfileActivity::class.java))
                    true
                }
                else -> false
            }
        }
    }

    private fun observeViewModel() {
        viewModel.isLoading.observe(this) { loading ->
            binding.progressBar.visibility = if (loading) View.VISIBLE else View.GONE
        }
        viewModel.products.observe(this) { products ->
            productAdapter.submitList(products)
            binding.tvEmptyState.visibility = if (products.isEmpty()) View.VISIBLE else View.GONE
        }
        viewModel.errorMessage.observe(this) { err ->
            binding.tvErrorBanner.visibility = if (err != null) View.VISIBLE else View.GONE
            binding.tvErrorBanner.text = err ?: ""
        }
    }
}

package id.ac.uas.myshopee.ui.payment

import android.content.ClipData
import android.content.ClipboardManager
import android.content.Context
import android.content.Intent
import android.os.Bundle
import android.os.CountDownTimer
import android.widget.Toast
import androidx.activity.viewModels
import androidx.appcompat.app.AppCompatActivity
import id.ac.uas.myshopee.databinding.ActivityPaymentBinding
import id.ac.uas.myshopee.ui.orders.OrderStatusActivity
import id.ac.uas.myshopee.ui.product.ProductGridAdapter
import id.ac.uas.myshopee.viewmodel.ShopeeViewModel

class PaymentActivity : AppCompatActivity() {

    private lateinit var binding: ActivityPaymentBinding
    private val viewModel: ShopeeViewModel by viewModels()
    private var countDownTimer: CountDownTimer? = null

    companion object {
        // Nomor Virtual Account BCA sesuai spesifikasi tugas UAS
        const val BCA_VA_NUMBER = "123 456 7890"
    }

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        binding = ActivityPaymentBinding.inflate(layoutInflater)
        setContentView(binding.root)

        val orderId = intent.getStringExtra("EXTRA_ORDER_ID") ?: "INV-20261008-001"
        val totalPayment = intent.getIntExtra("EXTRA_TOTAL_PAYMENT", 495000)

        binding.tvOrderId.text = orderId
        binding.tvVaNumber.text = BCA_VA_NUMBER
        binding.tvTotalPayment.text = ProductGridAdapter.formatRupiah(totalPayment)

        startPaymentCountdown()

        // Tombol Salin Nomor VA BCA (123 456 7890)
        binding.btnCopyVa.setOnClickListener {
            val clipboard = getSystemService(Context.CLIPBOARD_SERVICE) as ClipboardManager
            val clip = ClipData.newPlainText("Nomor VA BCA", BCA_VA_NUMBER)
            clipboard.setPrimaryClip(clip)
            Toast.makeText(this, "Nomor VA BCA 123 456 7890 berhasil disalin!", Toast.LENGTH_SHORT).show()
        }

        // Tombol Cek Status Pembayaran (Memanggil POST /api/payment/simulate?order_id=...)
        binding.btnCheckPaymentStatus.setOnClickListener {
            viewModel.verifyPaymentSimulation(orderId)
        }

        viewModel.currentOrder.observe(this) { order ->
            if (order != null) {
                binding.tvPaymentStatusBadge.text = order.status
                Toast.makeText(
                    this,
                    "Respons Backend: Status pesanan ${order.id} diperbarui menjadi ${order.status}",
                    Toast.LENGTH_SHORT
                ).show()

                // Buka Layar 11 (Status Pesanan)
                val intent = Intent(this, OrderStatusActivity::class.java)
                intent.putExtra("EXTRA_ORDER_ID", order.id)
                startActivity(intent)
            }
        }
    }

    private fun startPaymentCountdown() {
        countDownTimer = object : CountDownTimer(24 * 60 * 60 * 1000L, 1000L) {
            override fun onTick(millisUntilFinished: Long) {
                val hours = (millisUntilFinished / (1000 * 60 * 60)) % 24
                val minutes = (millisUntilFinished / (1000 * 60)) % 60
                val seconds = (millisUntilFinished / 1000) % 60
                binding.tvCountdownTimer.text = String.format("%02d:%02d:%02d", hours, minutes, seconds)
            }
            override fun onFinish() {
                binding.tvCountdownTimer.text = "00:00:00"
            }
        }.start()
    }

    override fun onDestroy() {
        countDownTimer?.cancel()
        super.onDestroy()
    }
}
